# Bug Report 02 — Absence de blocage sur la longueur maximale du nom

- Titre : Absence de blocage sur la quantité maximale de caractères pour le champ nom
- Contexte : Page de modification du profil utilisateur
- Préconditions : Être connecté à un compte utilisateur valide.
- Étapes :
  1. Se rendre dans les paramètres du profil.
  2. Cliquer sur le champ Nom et saisir une chaîne de caractères excessivement longue (plus de 255 caractères).
  3. Enregistrer les modifications.
- Résultat attendu : Un message d'erreur indique que la limite maximale de caractères est atteinte et l'enregistrement est bloqué.
- Résultat obtenu : La chaîne longue est acceptée et enregistrée, provoquant un dépassement de tampon ou une rupture de l'interface graphique sur la page d'accueil.
- Preuve : Troncature visuelle du nom dans la barre de navigation et log d'erreur SQL en base de données.
- Sévérité : Moyenne
- Priorité : Moyenne
